PROYECTO: CINE COLOMBIANO - PÁGINA INFORMATIVA Y JUEGO
Colegio Técnico Benjamín Herrera · 2026

ARCHIVOS
- index.html: estructura de la página y del juego.
- styles.css: colores, distribución y diseño adaptable a celulares y computadores.
- script.js: preguntas, respuestas, puntaje y mensajes del juego.

CÓMO ABRIRLO EN VISUAL STUDIO CODE
1. Extrae el archivo ZIP en una carpeta.
2. Abre Visual Studio Code.
3. Ve a Archivo > Abrir carpeta y selecciona la carpeta extraída.
4. Abre index.html.
5. Puedes hacer clic derecho sobre index.html y elegir "Open with Live Server" si tienes esa extensión.
   Si no tienes Live Server, también puedes abrir index.html directamente en el navegador.

CÓMO JUGAR
En la página, baja hasta la sección "Reto: cine colombiano". Responde las 8 preguntas.
Después de elegir una opción, aparecerá una explicación. Al final verás tu puntaje y podrás volver a jugar.

IMPORTANTE SOBRE EL CONTENIDO
Los porcentajes se presentan como resultados de la encuesta aplicada a 45 estudiantes, según la información de la tesis proporcionada para el proyecto. Las actividades de divulgación se describen como propuestas futuras: la investigación no implementó ni evaluó una intervención pedagógica.

REQUISITOS
No necesita base de datos, cuenta ni instalación de un motor de videojuegos. El juego usa HTML, CSS y JavaScript.
La fuente tipográfica en línea puede necesitar conexión a internet; la página y el juego siguen funcionando sin ella.
